# YYYY-MM-DD 금융 뉴스 — 대표 주제 1~2개

- 수집 상태: 정상 / 부분 수집 / 확인 가능 항목 없음 중 실제 상태
- 구성: 신규 N건 / 최근 이슈 해설 M건
- 대상 기간: 시작 ~ 종료 (Asia/Seoul)
- 실제 작성 완료: ISO 8601, +09:00
- 확인 범위와 한계: 실제 조사한 출처 및 누락
- 검증 기록: 해당 날짜 검증표 링크

## 오늘의 핵심

확인한 내용만 3줄 이내로 요약하고 각 주장에 출처 링크를 붙인다.

## 1. 독자적인 제목

**한 문장으로 먼저**: 금융 상식이 없는 사회초년생도 이해할 일상어 한 문장. 사실 근거 링크.

**무슨 일이 있었나**: 사실 2~3문장. 각 문장 끝에 근거 링크와 문장 ID를 붙인다.

**쉽게 설명하면**: 필수 용어부터 일상어로 풀어 쓴다. 다른 전문용어로 정의하지 않는다. 제도 자체를 모르는 독자도 이해할 수 있도록 설명하고 출처를 붙인다.

**이 뉴스의 의미 — 근거 있는 해설**: 무엇이 달라졌고 왜 살펴볼 만한지, 확인한 사실 → 원문·교육 자료가 설명하는 원리 → 적용 조건 순서로 2~3개의 짧은 문단으로 설명한다. 각 주장에 출처와 문장 ID를 붙인다. 출처의 평가라면 평가 주체를 밝힌다. 사실을 재진술하거나 용어만 정의하는 데서 끝내지 않는다.

**내 생활과의 연결**: 첫 월급·저축·카드·대출·주거비와 누구에게 어떤 조건에서 관련되는지 짧은 문장으로 설명한다. 실제 제도·계약 조건의 출처를 연결하고 개인의 이익·손실을 추정하지 않는다. 직접적인 관련성을 검증할 수 없으면 이 항목을 생략한다.

**아직 알 수 없는 점·알아둘 구분**: 신청/지정, 발표/시행, 관측 지표/정책 결정 등을 구분한다. 이 자료만으로 내릴 수 없는 결론과 근거의 범위를 설명한다.

**한눈에 보기**: 기사 속 말 / 쉬운 뜻 / 확인할 조건을 담은 짧은 표 또는 직접 만든 도식과 대체 설명. 모든 내용의 근거 링크.

**출처**: 기관, 자료명, 발표일(시간 미상이면 미상), 원문 URL.

## 수집 한계

본문에서 제외한 분야나 접근 실패를 명시한다. 조사하지 않은 분야에 뉴스가 없었다고 쓰지 않는다.

## 정정 기록

최초 발행 또는 실제 변경 시각·내용·사유·근거.

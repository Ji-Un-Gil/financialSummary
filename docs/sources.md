# 수집 출처

아래는 탐색 시작점이다. 매 실행에서 접속과 최신성을 확인하고 **개별 자료 URL**을 근거로 남긴다. 홈·목록 링크만으로 뉴스 주장을 뒷받침하지 않는다.

| 분야 | 우선 확인 기관 | 탐색 시작점 |
| --- | --- | --- |
| 정책·소비자 보호·금융업 | 금융위원회 | https://www.fsc.go.kr/no000000 |
| 감독·금융소비자 유의사항 | 금융감독원 | https://www.fss.or.kr/ |
| 통화·금융시장·통계 | 한국은행 | https://www.bok.or.kr/ |
| 금융·경제 시계열 | 한국은행 ECOS | https://ecos.bok.or.kr/ |
| 기업의 공식 공시 | DART | https://dart.fss.or.kr/ |
| 거래소 공시·시장 통계 | 한국거래소 | https://www.krx.co.kr/ |
| 해외 통화정책 | 미국 연방준비제도 | https://www.federalreserve.gov/ |
| 해외 통화정책 | 유럽중앙은행 | https://www.ecb.europa.eu/ |

국내 언론의 경제·금융 기사도 탐색해 공식 자료에서 빠진 후보를 찾는다. 동일 보도자료를 옮긴 기사 여러 개를 독립 검증 여러 건으로 세지 않는다. 검색어와 확인한 매체·기관, 접속 실패를 검증 기록에 남긴다. 위 기관에 새 자료가 없으면 관련 소식을 억지로 채우지 않는다.

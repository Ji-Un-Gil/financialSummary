# 금융 시사상식 요약정리

금융 초보자가 핵심 뉴스를 이해할 수 있도록, 확인한 사실을 짧고 쉬운 한국어로 설명합니다.

- 저장소: https://github.com/Ji-Un-Gil/financialSummary
- 매일 **18:30 Asia/Seoul**에 수집·작성 시작. 주말·공휴일 포함.
- 기본 대상: 전일 18:00 초과 ~ 당일 18:00 이하에 공개된 자료. 국내 금융권 중심, 국내 관련성이 큰 해외 금융 소식 포함.
- 시작 시각과 발행 시각은 다릅니다. 사실 확인이 끝난 뒤 저장합니다.
- 목표 분량: 하루 3~5건. 근거가 부족하면 줄이며, 개수를 맞추려고 내용을 만들지 않습니다.

## 운영 방식

이 작업에 연결된 Codex 예약 실행이 웹에서 원문을 확인하고, 보고서와 검증 기록을 이 저장소에 작성합니다. API 키를 사용하는 별도 수집 서버는 없습니다. 예약 실행 설정은 Codex 앱에 저장되며, 이 저장소를 복제하는 것만으로 예약이 생성되지는 않습니다.

로컬 실행에는 컴퓨터 전원, 앱 실행, 인터넷 연결 및 저장소 접근이 필요합니다. 정시 실행·무중단 운영을 보장하지 않습니다. 실패·지연·수집 범위 누락은 기록하고, 과거 시각에 발행한 것처럼 꾸미지 않습니다. 관련 [공식 예약 작업 문서](https://learn.chatgpt.com/docs/automations?surface=app).

자동 검사는 내용의 진실성을 보증하지 못합니다. 모든 사실 문장과 도표를 원문에 대조한 뒤 발행하며, 모르는 내용은 제외합니다. 원문을 재배포하지 않고 사실 중심의 독자적인 요약과 출처 링크를 제공합니다.
